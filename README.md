# RehabFlow (prototype)

Clickable, patient-side demo of asynchronous remote rehabilitation after ACL reconstruction.
The patient records exercises at home, gets live movement feedback from in-browser pose detection
(MediaPipe Pose), and a physiotherapist reviews the clips later.

- Open the GitHub Pages link and allow camera access for live feedback.
- Settings → "Demo mode (no camera)" plays a simulated recording instead.
- All pose processing happens on the device. Nothing is uploaded; there is no backend.
- All data is invented.

Prototype. Not a medical device. Feedback does not replace your physiotherapist.
